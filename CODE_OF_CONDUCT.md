# Zobdino Community Standards

Zobdino is an open-source project and expects professional, respectful collaboration.

## Expected behavior

- Discuss ideas and code, not personal attributes.
- Give specific, actionable technical feedback.
- Respect Persian-language and cultural context.
- Preserve attribution, licensing and source provenance.
- Avoid harassment, threats, discrimination, spam and deceptive behavior.
- Do not publish private information or credentials.

## Project moderation

Maintainers may edit, hide or remove contributions that violate these standards and may restrict participation when necessary to protect the project and its contributors.

## Scope

These standards apply to Issues, Pull Requests, Discussions, code review, documentation and other official Zobdino collaboration spaces.
