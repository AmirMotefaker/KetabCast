# Clearance Gate Registry

## Purpose

Separate evidence-backed research candidates from production-cleared catalog items.

## Required decision fields

- clearanceStatus
- jurisdiction
- editionRisk
- translatorRisk
- persianTranslationRisk
- productionAllowed
- firstReleaseCandidate
- humanReviewRequired

## Rule

Evidence-backed status is not production clearance. A candidate requires explicit review before production enablement.
