## About Zobdino

Zobdino is an open-source platform for **Persian / Farsi book summaries and short-form audio learning**.

We build a transparent pipeline that connects legal research sources to Persian summary scripts, text-to-speech, audio mastering, automated QA and verifiable GitHub releases.

### What we care about

- 🇮🇷 Persian-first product quality
- 🎧 useful short-form audio learning
- 🤖 AI-assisted but auditable production
- 🔎 transparent research and evidence
- 🔐 integrity checks for published media
- 🌐 open-source engineering
- ⚖️ copyright-aware content practices

## The pipeline

```text
Sources
  → Research
  → Persian Script
  → TTS
  → Audio Mastering
  → ASR / QA
  → Release Assets
  → zobdino.ir
```
