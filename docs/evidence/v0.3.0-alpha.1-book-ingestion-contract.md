# v0.3.0-alpha.1 — Book ingestion contract

Issue: [#100](https://github.com/Zobdino/Zobdino/issues/100)

## Scope

- Provider-neutral ingestion and job contracts.
- Ten registered format families across P0, P1 and P2.
- Full, Summary and Both processing modes.
- Sulafat and Iapetus product-domain voice IDs.
- Fail-closed encryption/DRM and rights-confirmation gates.
- Explicit OCR routing for scanned PDF, CBZ and CBR.

No upload endpoint, source file, generated book text, credential or production metadata changed in this milestone.
