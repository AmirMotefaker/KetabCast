# v0.2.0-beta.4 — Next-Gen Listening Experience

Issue: #42
Tracks: #8

## Free listening features
- one global audio session
- persistent global mini player
- on-device Resume / Continue Listening
- recent listening history contract
- Up Next + autoplay
- sleep timer: 15 / 30 / 45 minutes / end of episode
- timestamp bookmarks
- share episode URL with timestamp
- browser Media Session integration
- Space / J / L keyboard shortcuts
- direct production-audio download link
- transcript search
- exact click-to-seek whenever verified transcriptCues exist

## Privacy / cost
Listening progress, settings and bookmarks are stored locally in the browser.
No account, backend, subscription or paywall is required.

## Transcript truth
Current production episodes do not yet contain verified transcriptCues.
beta.4 does not invent timestamps. The transcript UI automatically enables
exact cue seeking after future QA/promotion provides verified cues.

## Integrity boundary
- production MP3 mutation: NO
- `src/content/episodes.json` mutation: NO
- content-factory catalog mutation: NO
- historical evidence mutation: NO
