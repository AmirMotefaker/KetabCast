# v0.2.0-beta.4.2 — Verified New-Episode Append

Issue: #47
Tracks: #8

The production promoter can now append an absent episode, but only through
`buildVerifiedReadyEpisode` after all local/remote integrity checks pass.

## Required before append
- catalog/generated identity match
- inspection episode match
- verified remote asset
- objectKey match
- SHA-256 match
- bytes match
- positive duration
- GitHub production URL

## Recovery
- r1 stopped before commit/push during README update
- root cause: a Markdown backtick sequence in a double-quoted PowerShell
  anchor changed the runtime string
- r2 fixed the Markdown anchors but stopped before commit/push while parsing
  package-lock.json because ConvertFrom-Json cannot represent an empty-string
  property name as a PSCustomObject
- r3 uses ConvertFrom-Json -AsHashTable for package/package-lock version checks
  and resumes the existing local branch without reset/clean

## Integrity
This prep release does not modify `src/content/episodes.json` or any MP3.
