- The first short WAV is deleted and never checkpointed.
- The second attempt uses explicit complete-recitation director notes requiring every transcript word to be spoken through the end.

- Pending Interaction ID semantics, same-ID polling, SSE streaming, quota handling, and terminal content_blocked protection remain unchanged.
