## Root cause
The site uses Next static export. Without `trailingSlash: true`, dynamic
static pages are emitted as `out/books/<slug>.html`. GitHub Pages does not
provide an application-server rewrite from the desired trailing-slash route
to that HTML file.

## Recovery
- enable `trailingSlash: true`
- require `out/books/atomic-habits/index.html` after local build
- verify direct GitHub Pages deep link returns HTTP 200
- only then create exact-SHA `v0.2.0-beta.4` tag and Release
