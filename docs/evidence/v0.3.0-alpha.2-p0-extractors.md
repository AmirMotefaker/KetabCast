# v0.3.0-alpha.2 — Secure P0 extractors

Issue: [#104](https://github.com/Zobdino/Zobdino/issues/104)

## Scope

- EPUB container verification and spine-ordered text extraction.
- Archive traversal, encryption and bounded resource gates.
- Digital PDF extraction through a provider-neutral Poppler adapter.
- Page provenance and low-text PDF routing to `ocr-required`.
- Generated, rights-safe fixtures only.

No user file, copyrighted book text, public metadata, audio asset or production page changed.

## Security boundaries

- No shell interpolation: PDF tools receive an argument array.
- Temporary source files use a unique directory, mode `0600`, and unconditional cleanup.
- Source text is returned to the caller and never logged.
- Encrypted containers fail closed.
- Archive bytes, entries, per-entry expansion, total expansion and compression ratio are bounded.

## Validation

Run:

`node --experimental-strip-types packages/ai-pipeline/src/extractors/self-test.ts`

The self-test creates its EPUB and PDF inputs in memory and validates ordering, provenance, spoof rejection, traversal rejection, resource limits and OCR routing.
