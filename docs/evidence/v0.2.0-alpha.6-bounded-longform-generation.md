## Fix

- Structured JSON is limited to compact plan/metadata.
- Workers AI plan requires exactly five key ideas.
- Spoken transcript is generated in seven bounded sections.
- Opening acceptance: 160–260 words.
- Each of five ideas: 260–360 words.
- Closing acceptance: 180–300 words.
- Each failing section gets up to three bounded rewrite attempts.
- Final transcript must pass the existing 1500–2500 word safety gate.
- Section attempt/word-count metadata is saved in script-sections.json and qa.json.
- No publish/ready/SoundHelix mutation occurs in this fix milestone.
