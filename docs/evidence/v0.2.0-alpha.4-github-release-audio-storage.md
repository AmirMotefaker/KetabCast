# v0.2.0-alpha.4 — GitHub Release Audio Storage

Issue: #14

## Decision

Cloudflare R2 activation requires account billing activation. To keep KetabCast free-first and card-independent for v0.2, production audio storage is migrated to GitHub Release Assets.

## Integrity gate

- Generated MP3 passes Piper/FFmpeg/faster-whisper/audio-inspect first.
- Media assets are staged in an immutable media tag/release.
- GitHub asset size and API SHA-256 digest are checked.
- Every public browser_download_url is downloaded again.
- Download-back bytes and SHA-256 must match the local inspected file.
- Episode metadata is promoted to ready only after all checks pass.

## Scope truth

- This alpha.4 milestone changes storage orchestration only.
- No real production episode is marked ready by this migration itself.
- SoundHelix remains until beta.1 publish succeeds.
- R2 tooling remains available but optional.
- No secrets or payment data are committed.
