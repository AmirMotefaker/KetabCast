# v0.2.0-beta.5.1.11 — Dual-Voice Checkpoint Resume

## Trigger

Controlled `batch-a-atomic` run `31615165328` failed while generating
Atomic Habits / Sulafat chunk 2 after chunk 1 had already been successfully
persisted.

- failed source SHA: `55f4fae8802a91d4dbce312ee6a1d459164bc8e6`
- failed artifact ID: `9149552080`
- failed artifact digest:
  `sha256:a79747db4075ad1dd705d58165cb3b82ef8f8018b51bce7f6e1399051e914f36`
- checkpoint contents included:
  `atomic-habits/female/chunks/01.wav`
- provider terminal cause:
  `generate_content_free_tier_requests` HTTP 429

## Fix

- optional `resume_run_id` is accepted by the production workflow;
- the resume source must be a failed workflow_dispatch run from the exact
  dual-voice production workflow;
- the failed source SHA must be an ancestor of the current source SHA;
- the matching failed artifact name and GitHub SHA-256 digest are verified;
- checkpoint WAVs are re-indexed from the archived spoken script;
- current generation independently re-verifies:
  - book / role / provider voice;
  - full spoken-script SHA-256;
  - deterministic chunk SHA-256;
  - WAV SHA-256;
  - WAV duration;
  - source run / source SHA / artifact digest;
- every successful current or resumed chunk writes a checkpoint sidecar;
- a resumed chunk does **not** populate the in-process
  `successfullySynthesizedTextHashes` set and therefore cannot authorize
  content-blocked recovery as though it had been synthesized in the current
  process;
- a Gemini free-tier request-window 429 now fails closed after the first such
  response so repeated same-run POST retries do not burn the provider window;
- generic transient, explicit daily quota, and free-tier request-window
  classifiers have separate deterministic tests.

## Unchanged safety boundaries

- generation network hard cap remains 10;
- transcript and TTS safety settings are unchanged;
- no production episode metadata is promoted by this code release;
- no existing production player/audio is replaced;
- media target remains `media-dual-v0.2.0-beta.6`;
- production resume is a separate controlled dispatch after this release.
