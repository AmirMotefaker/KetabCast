## Contract

- Only a result already validated as checkpointReused may seed the successful transcript hash set.
- The seeded hash is the deterministic current chunk SHA256 already matched by resumeGeneratedChunk provenance validation.
- checkpointReused=false does not seed recovery state.
- Invalid hash values fail closed.
- Existing content_blocked recovery caps remain unchanged:
  - previously synthesized transcript only
  - maximum recovery POSTs unchanged
  - classifier-block cap unchanged
  - hard network request cap unchanged
  - free-tier 429 and transient retry behavior unchanged
- No provider response is bypassed and no new transcript becomes recovery-eligible without a verified successful checkpoint or an actual successful synthesis.
